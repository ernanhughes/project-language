## Human review before any pilot

1. The task author supplies source text, source hash and exact questions. The independent reviewer reads the source first, writes supported decisions and uncertainty, then compares with the proposed reference. Record disputed wording and permitted alternatives; do not silently settle ambiguity.
2. Check every exception, quantifier, distinction and authority condition against an exact passage. Confirm the abstention boundary and whether the question itself overstates what the source can decide. Verify positive and negative controls and counterexamples, not just the expected answer.
3. Record distinct identities, dates, source hashes and explicit approvals in a prospective version. Equal author/reviewer identities do not count as independent review. No script can create or authenticate human judgment by filling these fields.
4. Freeze approved source-bound criteria before real responses. Blinded response adjudicators assess each question and claim without model/arm labels when practical. Metadata blinding cannot hide every representational cue. Record disagreements and unassessable cases.

## Separate measurements, without an aggregate quality score

| Axis | Required human judgment / observation |
|---|---|
| Reconstruction | Supported decision, accepted alternative, unsupported, or unassessable |
| Distinctions | Each critical scope, exception, condition and uncertainty preserved/lost/reversed/unassessable |
| Additions | Each introduced assertion, supporting span or reason no support exists |
| Abstention | Appropriate UNKNOWN, unjustified certainty, or delivery capacity limitation |
| Authority | False permission, maintained prohibition/condition, or unresolved derivability |
| Resources | Full source/wire/quote bytes; reported versus bounded/unknown tokens; elapsed time; correction overhead |
| Coverage | Planned, admitted, completed, refused, malformed, truncated, cancelled and failed calls |

The current host compares decisions and verbatim quote support ONLY as authored diagnostics. It does not assess all paraphrases or entailment and cannot turn matching decisions into a primary score. Primary preservation/addition/uncertainty/abstention cells remain NOT_ADJUDICATED. An omitted condition in the channel can make the task underdetermined; do not automatically call a sensible refusal a model error.

## Advisory judge controls

Two deterministic adversarial controls deliberately (a) have C endorse a fluent but unsupported permission and (b) have C reject a valid UNKNOWN. Record scripted false endorsements and missed valid refusals separately. These demonstrate instrument behavior under supplied labels, not observed errors by GLM or any other model. Actual judge FP/FN rates require independently adjudicated positive and negative controls; no such rates or human agreement statistics exist yet.

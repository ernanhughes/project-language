## Architecture and implementation

Language Studio is a new first-class app at `apps/language-demo/`. The canonical app object is a source-bound, versioned semantic proposal, not the transcript. Separate events record model proposals, challenges, clarifications, acceptance/rejection, sealed deliveries, recipient observations and errors. Source truth, mechanical binding, acceptance and action authority remain separate.

The app directly reuses canonical JSON and SHA-256 from `core/evidence/src/canonical.ts`. Existing document-record, preservation, authority, Pi and historical Workbench/Capstone responsibilities were inspected. Their contracts informed boundaries; this app does not replace them or claim their earlier evidence. A simple stateless Ollama text adapter avoids adding an agent framework or exposing tools. No paid adapter, plugin installation or remote authentication is implemented.

Files: six LC-00 design documents under `docs/`; executable schemas in `protocol/state.mjs`; synthetic M-12 scenario and event-driven Studio engine under `engine/`; configurable fixture/Ollama runtime and local probe under `models/`; JSONL storage under `storage/`; local HTTP server and self-contained HTML export under `server/`; browser UI under `ui/`; deterministic and browser tests under `tests/`; README, package scripts and new evidence under this application directory. No pre-existing repository file was edited.

Launch from `C:\Projects\project-language`:

```powershell
node --experimental-transform-types apps/language-demo/server/app.mjs
```

Open the printed free loopback port. The default backend is explicitly SCRIPTED_FIXTURE. One exchange persists per data directory; use `--data NEW_DIRECTORY` for another exchange without deleting earlier evidence. Replay loads captured state and responses, never invokes a model.

## Limits and next milestone

- Local model path is exercised but **not successfully qualified**. The real truncated output is preserved unaltered. The UI permits manual selection of other installed local weights; no automated model substitution occurs.
- Advisory-evaluator role is reserved/configurable in the runtime but not executable; UI marks it deferred. No independent semantic adjudication is claimed.
- Context is wholly refused in v0.1. There is no contextual memory, arbitrary graph ontology, external action execution or multi-user authentication/identity service.
- The single-operator loopback application is a development tool. Hash chaining detects changed captured bytes; it is not signed proof of human identity or an adversarial audit service.
- Fixtures are specific to synthetic M-12 and are not a general interpreter of arbitrary edited sources. Small-model structured output remains an engineering challenge.
- Sender generation closes after question exposure, intentionally restricting iterative editing within that exchange. Use a new exchange directory for further development.
- Comparison is a visible development instrument. M-12 is exposed, not held-out material. Fluent output, source quotation and field repetition do not prove understanding.

Execution

Pressing Start Comparison or Run interpreter calls your configured OpenCode Go model. There is no separate execution-approval step. You still decide whether to accept a proposed meaning.

The key comes only from OPENCODE_API_KEY in the server process environment. Settings never store your key.

Your models

Four default models cover five roles. The mediator shares DeepSeek with the interpreter. Start Comparison uses the interpreter and recipient; it does not call every role.

Haiku is configured for optional advisory review. Advisory execution is not implemented and is not part of the comparison.

Understanding Compiler

Local spaCy/NLTK analysis proposes meanings before and after communication. Its labels are heuristic and completeness is not evaluated. No model or corpus downloads are automatic.

A missing dependency stops this analysis explicitly; it is never replaced with an AI-generated inventory. Changing the profile during review requires a new comparison.

Request limits

Completion limits default to 16,384 tokens per role. Streaming data has a separate byte limit. Limits remain finite, and there are no automatic retries or fallback models.

Saving settings does not reset used requests or failed attempts. This page makes no model requests.
